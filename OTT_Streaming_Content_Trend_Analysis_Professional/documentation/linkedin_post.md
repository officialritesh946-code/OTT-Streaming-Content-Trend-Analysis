🚀 OTT Streaming Content Trend Analysis — Project Completed

I completed an end-to-end OTT content analysis project using a Netflix catalog dataset.

📊 Analysis covered:
• Movie vs TV Show mix
• Genre/category distribution
• Titles added over time
• Release-year trends
• Ratings
• Country-level representation
• Data-quality checks

🔎 Key observations:
• Movies represent 69.6% of the available catalog.
• 2019 was the peak year for titles added.
• International Movies was the most frequent category after expanding multi-category records.
• United States was the most represented country in the available country data.

🛠 Tools: Python | Pandas | NumPy | Matplotlib | SQL | Excel
